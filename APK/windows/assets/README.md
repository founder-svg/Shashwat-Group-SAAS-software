# Client Logo & App Icon Assets

Place the client's official logo files here:

1. `logo.png` - High-resolution logo image (512x512 pixels recommended).
2. `icon.ico` - Multi-size Windows Icon file (contains 16x16, 32x32, 48x48, 256x256).

### How to create `icon.ico` from client's logo:
1. Provide the logo image (`.png` or `.jpeg`).
2. We can automatically convert it to `.ico` format.
3. The generated desktop shortcut and installer will automatically use this icon!
